# Neha Vadapally - Data Analytics Portfolio

A collection of analytical and data engineering projects demonstrating skills in Python, SQL, geographic data processing, time‑series analysis and large‑scale data pipelines.  
This repository brings together independent projects built using open data, reproducible workflows and clear analytical documentation.

---

Each folder contains Jupyter notebooks, scripts or SQL files along with outputs or visualisations relevant to the analysis.

---

## **Project Summaries**

### **1. Financial Time-Series Forecasting**
Multi‑year forecasting with seasonal decomposition, ARIMA/SARIMA modelling and rolling-window evaluation.  
Focus: identifying stability, structural shifts and forecast reliability.

### **2. MT Ticket Sales Datamart**
End‑to‑end datamart design using star schema principles.  
Focus: relational modelling, SQL transformations and BI-ready datasets.

### **3. PySpark Titanic Classification**
A full supervised ML pipeline created in PySpark.  
Focus: feature engineering, imputation, categorical encoding and baseline models with accuracy, precision, recall and F1.

### **4. Spark Police Data Analytics**
Processed over **four million** UK police records using Spark SQL.  
Focus: temporal aggregation, spatial grouping, large-scale ETL, event data pipelines.

### **5. UK College Contact Hours Analysis**
Applied statistical and comparative methods to understand variation in education metrics.  
Focus: non‑parametric testing, robust regression and factor-based comparison across regions and institution types.
