**Data Source**

The analysis uses over four million UK police street‑level crime records obtained from the official [Police Open Data portal](https://data.police.uk/data/).

* The original data covers multiple cities and multiple years, downloaded as monthly CSV files for each police force.
* These files include detailed attributes such as location, crime category and outcome status.
* For ease of testing and demonstration, a small sample subset of the data is included in the sample/ directory of this repository. 

The full dataset is significantly larger and was processed using Apache Spark to support large‑scale analytical queries.
