**Large Scale Police Crime Data Analytics with Spark SQL**

This project performs large scale analysis on open police data using Apache Spark. 

The dataset spans multiple cities and multiple years, enabling cross‑regional and temporal comparisons.

**Key work undertaken**

* Data extraction, cleaning, normalisation and transformation using Spark DataFrames
* Multi‑city multi‑year crime trend analysis
* Investigation of crime categories, spatial variation and distribution patterns
* Use of Spark SQL for aggregation, filtering and analytical queries
* Visualisation of results and discussion of insights derived from large scale processing
* Reflection on data quality, scalability and analytical limitations
