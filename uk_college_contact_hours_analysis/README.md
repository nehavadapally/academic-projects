**Analysing Contact Learning Hours in UK FE and Sixth Form Colleges Using SAS**

This project investigates the factors that influence Contact Learning Hours (CH) across UK Sixth Form and Further Education colleges. Using three datasets containing CH totals, learner counts, graduation pass rates, gender ratios and Value Add Factor (VAF), the project applies SAS programming to examine how region, institution type, institution size and year affect CH per learner.

The study integrates data cleaning, descriptive statistics, exploratory analysis and two statistical modelling approaches to provide insights into institutional performance.

**Key work undertaken**

* Import and clean three supplied datasets
* Classify institutions into size groups based on learner ranges
* Produce data summaries and identify anomalies
* Conduct exploratory data analysis, including correlations and distribution checks
* Implement non‑parametric tests (NPAR1WAY)
* Fit a robust regression model (ROBUSTREG)
* Validate model assumptions and interpret findings
