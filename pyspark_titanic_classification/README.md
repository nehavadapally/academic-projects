**Titanic Classification Modelling with PySpark MLlib**

This project develops a classification pipeline using PySpark MLlib applied to the Titanic survival dataset.

**Key work undertaken**

* Data cleaning, handling missing values and feature normalisation
* Feature extraction and selection for model readiness
* Model development using MLlib classification algorithms
* Evaluation using accuracy, confusion matrices and statistical metrics
* Comparison of model performance and refinement across multiple trials
* Discussion of model assumptions, interpretability and practical implications
