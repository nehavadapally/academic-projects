**Data Source**

This dataset contains passenger records from the RMS Titanic and is used for the classification task in the PySpark MLlib project. 
It includes demographic information, ticket details and survival outcomes for each passenger. The dataset supports tasks such as data cleaning, feature engineering and machine learning model development.

**About the File**

[TitanicData1.csv](https://github.com/nehavadapally/academic/blob/main/pyspark_titanic_classification/data/TitanicData1.csv) contains fields such as:

* Passenger class
* Name
* Sex
* Age
* Number of siblings or spouses aboard
* Number of parents or children aboard
* Fare
* Cabin (where available)
* Port of embarkation
* Survival outcome (0 or 1)
