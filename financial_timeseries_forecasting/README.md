**Financial Time Series Analysis**

This project analyses a real financial time series obtained from [NASDAQ](https://www.nasdaq.com/) using monthly close prices with a minimum of sixty observations. 

Applied a range of time series methods to understand structure, diagnose behaviour and develop forecasting models.

**Key work undertaken**

* Time series decomposition into trend, seasonal and residual components
* Evaluation of additive and multiplicative effects
* Forecasting using baseline, naïve, simple average and exponential smoothing methods
* Stationarity testing using the Dickey - Fuller test
* Model selection using ACF, PACF and AIC for ARIMA and SARIMA
* Time series regression using lagged variables
* Forecast accuracy comparison across all models
* Python implementation with visualisation, exploratory statistics and model diagnostics
