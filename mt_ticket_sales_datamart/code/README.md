
This directory contains the SQL scripts used to build and test the Midlands Theatre ticket‑sales data mart.

* ETL.sql - Loads the dimensions and fact table by extracting and transforming data from the source tables.
* datamart_vs_oltp.sql - Runs the required analysis queries on both the OLTP schema and the data mart for comparison.
* schema.sql - Creates all data mart tables and defines their primary and foreign keys.
