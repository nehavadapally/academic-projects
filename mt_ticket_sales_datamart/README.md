**Midlands Theatre (MT) Company Ticket Sales Data Mart**

This repository contains a prototype data mart developed for the Midlands Theatre (MT) organisation. 
The purpose of the data mart is to support analytical reporting on ticket sales using data originally stored in the ops$yyang00 Oracle schema. The data mart is based on the booking and ticketing processes described in the scenario and follows best practice in dimensional modelling.
Only data involved in at least one ticket sale is retained in the datamart.

**Objectives:**

1. Total sale value per production
2. Monthly sale value per theatre
3. For each theatre, the client(s) with the highest spending

“Sale value” refers to monetary value, not ticket count.
